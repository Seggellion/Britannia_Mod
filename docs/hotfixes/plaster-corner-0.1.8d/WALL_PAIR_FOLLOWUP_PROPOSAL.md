Status: **PROPOSAL_ONLY — NOT IMPLEMENTED**. Plaster acceptance is held by the [reproduced pre-existing defect](MIRROR_MISMATCH_DIAGNOSIS.md). This proposal does not waive it, change the candidate or authorize a wall-system rewrite/live-world migration.

1. Add a narrow DoubleWall paired-edit operation used by the decorator. Resolve the LOWER anchor, verify both IDs and opposite HALF, reject a missing/mismatched counterpart, and preserve each HALF. Apply structural FACING/SHAPE/BRANCH_RIGHT and, when present, MIRRORED consistently to both blocks before publishing neighbor notifications. Keep unrelated decorator paths unchanged. Review style/variant properties explicitly rather than copying arbitrary states from one half.
2. Establish one physical-run conversion: a mirrored non-straight uses BRANCH_RIGHT XOR MIRRORED. Use it for DoubleWall peers and the full-wall peer path in PlasterWallHalfBlock. Derive physical edges, then convert the result back to the stored branch for that state's mirror. Do not add fictitious MIRRORED/HALF properties to half blocks.
3. Audit vanilla rotation/mirror dispatch so physical edges transform exactly once. The present superclass branch flip plus subclass mirror toggle and post-placement normalization must not invert the rendered branch twice. Keep a paired edit consistent under subsequent neighbor derivation; synchronization alone is insufficient.
4. Review authored variant selection before implementation. Normalization of 90/270-degree unmirrored structures selects existing true-branch two-post art. Preserving literal one-post structure transforms may require a separate selector/layout decision. Do not change the false-branch one-post relocation contract, silently relocate true-branch posts, or disguise topology errors with a mesh. Specify expected physical joins and post layout for each normalized transform before changing shared behavior.
